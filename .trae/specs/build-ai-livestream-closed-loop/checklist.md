# Checklist

## 平台接入网关
- [ ] 统一弹幕/指标消息模型定义完整，所有适配器输出符合该模型
- [ ] 模拟弹幕源可按场景（高频提问/负面刷屏/购买意向）回放弹幕序列
- [ ] 适配器可通过配置切换（mock ↔ browser ↔ official），决策中枢与前端无感知
- [ ] 官方 API 适配器为禁用占位，含抖音/淘宝/快手配置开关
- [ ] 网关具备断线重连与本地消息缓冲，重连期间消息不丢失

## 场次与持久化
- [ ] LiveSession / DanmakuMessage / DecisionRecord / LiveMetric 四张表建模与建表脚本就绪
- [ ] 场次生命周期（创建→直播中→结束）状态流转正确，弹幕/决策/指标均关联场次
- [ ] 场次结束后可回放查询整场弹幕与决策历史

## WebSocket 实时通道
- [ ] `/ws/live/{session_id}` 推送 danmaku/decision/metric/stage 四类消息
- [ ] 客户端断线自动重连并按 last_event_id 补拉增量
- [ ] REST `POST /agent/decide` 行为与改造前兼容

## 决策中枢
- [ ] LLM 互动理解输出意图/情绪/高频问题结构化结果
- [ ] LLM 超时或失败时 500ms 内降级到规则方案，结果标记 degraded=true
- [ ] 导演脚本 JSON 符合 spec 定义格式（lines/emotion/action/pace/show_product_card 等）
- [ ] 剧本导入后能约束阶段切换与话术风格
- [ ] 每条决策自动写入 DecisionRecord
- [ ] 弹幕进入 → 导演脚本产出全链路延迟 ≤ 2 秒

## 展示适配层
- [ ] TTS 引擎可配置（CosyVoice / 商用 API），产出音频 + 字幕 JSON + 动作指令包
- [ ] 台词进入 TTS 前强制过合规模块；含违禁词且无替代方案时拦截并告警
- [ ] 2D 形象驱动：底版素材支持真人录制/照片/AI 生成三种来源并可轮换
- [ ] 新台词（从未预录）经 TTS 合成后可实时驱动口型渲染数字人画面
- [ ] 动作建议映射为画面层操作（商品特写贴片/素材切换/叠加物），非实时生成肢体动作
- [ ] 无 GPU/驱动模型未就绪时自动降级为"TTS + 字幕"形态，决策链路不受影响
- [ ] "AI 生成内容"标识叠加能力就绪且可配置

## 浏览器采集兜底
- [ ] 浏览器端采集脚本可回传并归一化进统一消息模型
- [ ] 文档明确官方渠道资质要求与浏览器采集的风险提示

## 实时数据反馈与策略优化
- [ ] LiveMetric 可从模拟源/监场台注入并入库
- [ ] 策略引擎基于滑动窗口指标动态调整决策权重，含 3~5 条可配置基础规则
- [ ] 每次策略调整记录原因与前后权重快照，可查询

## 前端监场台
- [ ] WebSocket 实时展示弹幕流、导演脚本、阶段进度、指标曲线
- [ ] 一键接管：暂停自动决策、手动话术（过合规检查）、一键恢复
- [ ] TTS 音频可在前端播放

## 端到端验证
- [ ] 模拟源全链路跑通：弹幕注入 → 决策 → 导演脚本 → 合规 → TTS → 监场台展示
- [ ] 指标回流验证：注入数据 → 策略调权 → 决策行为变化可观测
- [ ] 异常场景验证通过：LLM 降级、断线重连、合规拦截
